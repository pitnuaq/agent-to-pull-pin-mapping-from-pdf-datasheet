## Tool: save_pinout_to_db
- **Description**: Saves the entire extracted pinout configuration as a clean, standardized JSON array blob directly into a single column inside the 'master_components' SQLite table.
- **Inputs Required**:
  - `part_number`: The specific MPN being processed.
  - `pin_assignments`: The raw JSON array output generated by the read_datasheet tool.
- **Execution Rules**: Invoke this immediately after successfully retrieving the JSON string from the datasheet. Do not alter the JSON array structure before passing it to this tool.
